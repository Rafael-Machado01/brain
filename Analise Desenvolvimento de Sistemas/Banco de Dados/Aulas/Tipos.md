# Tipos de Dados

No banco de dados, precisamos selecionar qual o tipo do dado que vamos guardar são eles:

Todos os tipos são seguidos ao número limite que o dado pode chegar.
```
number(2);
Exemplo: Número com duas casas = 10
````


# Number
```
Números em geral. 
Podemos usar também float e int
```

# Char
```
Caracteres - Letras Palavras.
Numeros e Simbolos
Tudo armazenado como texto e não variáveis
````

# Varchar 
```
Igual ao Char, porém não é preciso preencher o limite imposto. Ele pode ir até o limite ou não.
````

# Time
```
Armazena horário.
````

# Date
```
Armazena Datas.
````

# Datetime
```
Data + Hora
```
