# Estrutura Básica

```
algoritmo nome_do_algoritmo
var
declare_variaveis
inicio
imprima "olá mundo!";
fim.
```

# Imprima
Usado para mostrar algo na tela do usuário pode ser string, variáveis, contas.

# Leia
Usado como se fosse um prompt para o usuário como um campo que ele digita. Por exemplo algo como : "Quanto é 2 + 2", no prompt ele colocaria o resultado.
