# Lista (FIFO)

**FIFO** — *First In, First Out* — é o princípio fundamental de uma fila: o primeiro elemento a entrar é o primeiro a sair. Não pode furar fila.

## Como funciona

1. **Enqueue** — insere um elemento no final da fila.
2. **Dequeue** — remove o elemento do início da fila.

## Exemplo simples

```
Fila inicial:  A  B  C   (entra A, depois B, depois C)
Remoção:       → A é removido primeiro (foi o primeiro a entrar)
Fila restante: B  C
```
