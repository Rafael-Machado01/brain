# Numeros reais

## Resumo

Os números reais (ℝ) são infinitos tanto para o lado negativo quanto para o lado positivo.

Características do Conjunto dos Reais ($\mathbb{R}$):

- **Infinito:** Não possui um primeiro nem um último elemento.
- **Sem limites:** Vai do infinito negativo ($-\infty$) ao infinito positivo ($+\infty$).
- **Denso:** Entre quaisquer dois números reais, existem infinitos outros números reais.

Hierarquia (cada conjunto cabe dentro do próximo):

$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$

- **ℕ** naturais: 0, 1, 2, 3...
- **ℤ** inteiros: ..., -2, -1, 0, 1, 2...
- **ℚ** racionais: frações e decimais exatos (1/2 = 0,5)
- **ℝ** reais: tudo isso + irracionais (√2, π)

## Conceitos-chave

> [!important] Conceito Principal
> Os reais são infinitos e densos: entre dois reais quaisquer existe sempre outro real.

É por isso que quando uma condição é sobre ℝ (ex: -1 ≤ x ≤ 6 em [[Como descobrir conjuntos]]), existem infinitas soluções — diferente de ℤ, onde daria pra listar.

## Código / Exemplos

```js
// em programação, float é uma tentativa de representar os reais
const reaisSequencia = [1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0];
// entre 1.0 e 1.5 ainda caberia infinitos valores: 1.01, 1.001, 1.0001...
```
