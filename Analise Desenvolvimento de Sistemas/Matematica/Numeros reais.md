# Numeros reais

## Resumo

Eles são infinitos tanto para o lado negativo quanto para o lado positivo.

Características do Conjunto dos Reais (\(\mathbb{R}\))

- **Infinito:** Não possui um primeiro nem um último elemento.
- **Sem limites:** Vai do infinito negativo (\(-\infty \)) ao infinito positivo (\(+\infty \)).
- **Denso:** Entre quaisquer dois números reais, existem infinitos outros números reais.
