# Diagrama de Flechas

## Resumo

Forma de representar uma [[Relação]] entre dois conjuntos: elementos de A de um lado, elementos de B do outro, e setas ligando cada par ordenado (x, y).

Cada seta sai de x (em A) e chega em y (em B) — **uma seta por par da relação**.

## Conceitos-chave

> [!important] Conceito Principal
> Cada seta representa um par ordenado (x, y): origem = primeiro elemento, chegada = segundo elemento.

- Todo elemento de A que recebe seta saindo → faz parte do **domínio**
- Todo elemento de B que recebe pelo menos uma seta chegando → faz parte da **imagem**

## Código / Exemplos

```
A×B com setas:  A={1,2}  B={2,3}

1 -> 2
1 -> 3
2 -> 2
2 -> 3
```

(4 setas = os 4 pares de A×B)

Se fosse só uma relação R = {(1,2), (2,3)}, desenharia apenas as setas:

```
A          B
1 ──────►  2
2 ──────►  3
```

(2 setas = os pares que satisfazem a condição)
