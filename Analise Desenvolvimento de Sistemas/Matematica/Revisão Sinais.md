# Operações com Números Inteiros

# Operações com números inteiros (Soma e subtração)
1- Caso: Sinais iguais
	Regras: Soma os números e conserva o sinal.
Exemplo
1)+5+10+3=+18
2)-2-3-23=-28

2- Caso: Sinais diferentes
	Regras: Somar os números de mesmo sinal e subtrair e conservar o sinal do número maior.
Exemplo
1)+5-7+10-25= +5 + +10 = +15 -7 - -25 = -32 = -32 - +15 = -18

# Operações com números inteiros (Multiplicação e Divisição)

Regra de sinal:

# Multiplicação
(+) x (+)= +
(-) x (-) = +
(+) x (-)= -
(-) x (+) = -

# Divisão
(+) : (+)= +
(-) : (-) = +
(+) : (-)= -
(-) : (+) = -

Exemplo:
1) (+25) x (+2) = + 50
2) (-25) x (-2) = +50
3) (+25) x (-2) = - 50
4) (-25) x (+2) = - 50
5) (+15) : (+3) = + 5
6) (-15) : (-3) = +5


# Adição e subtração de números inteiros (com parênteses)
 Para eliminar os parênteses utilizar a regra de sinal do produto.
	+ ( + ) = +
	+ ( – ) = –
	– ( + ) = –
	– ( – ) = +

Exemplo: 
1) +(+5) - (-7) + (+10) + (-13) - (+25) =
+5+7+10-13-25 = +22-38 = -16
2) +(-2) - (+15) - (-23) + (+11) =
-2-15+23+11 = -17+34 = +17
