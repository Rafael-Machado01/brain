# Plano Cartesiano

* Sejam A e B conjuntos não vazios.
1. Ache o número de elementos dos conjuntos
2. Multiplique N(AxB)
3. O primeiro elemento de A com o primeiro elemento de B ....
4. O segundo elemento de A com o primeiro elemento de B ....
5. Faça o diagrama de Venn

Isso é Fácil

# Exemplo
1 - Dado o conjunto A = {1,2} B = {a,b}
```
N(AxB) = 4
A x B =  (1,a), (1,b), (2,a), (2,b)
B x A = (a,1), (a,2), (b,1), (b,2)
````
