# Igualdade de Conjuntos

Dois conjuntos são iguais quando todos os seus elementos são idênticos.

Se
````
A={0,1,2,3,4,5} e B={5,4,3,2,1,0}
São iguais, não importa há ordem.
````

Se
````
C={A,E,I,O,U} e D={E,I,U,O,A}
Igual
`````

Se 
```
E={0,1,2,3} e F={0,1,1,2,2,2,3}
São iguais, não importa a repetição.
````
