# Operações com Conjuntos

Exemplo Conjunto
````
A={1,2,3,4} 
B={3,4,5,6}
````

# União U
E só colocar oque tem sem repetir
```
AuB={1,2,3,4,6}
````

# Interseção ∩
Elementos repetidos no A e no B
```
A∩B={3,4}
````

# Diferença -
São os elementos que não se repete no B
```
A-B={1,2} 
o 3 e 4 se repete no b então não vao e o 5 6 não vai pq ja acabou o A
````
