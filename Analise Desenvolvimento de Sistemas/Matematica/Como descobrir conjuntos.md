# Como descobrir conjuntos

## Resumo

Como descobrir este conjunto = {x ∈ ℝ / -1 ≤ x ≤ 6}

Lendo a notação construtora de dentro pra fora:

1. `x ∈ ℝ` → o x faz parte dos [[Numeros reais]]
2. `/` (ou `|`) → "tal que", separa o elemento da condição
3. `-1 ≤ x ≤ 6` → condição: x tem que estar entre -1 e 6 (inclusive)

Ou seja: **todos os x reais que estão entre -1 e 6**.

> ⚠️ Atenção: se o x fosse ℝ de verdade, a resposta seria infinita. Esse exemplo lista só os inteiros entre -1 e 6 (na prática, x ∈ ℤ).

## Conceitos-chave

> [!important] Conceito Principal
> Notação construtora {x ∊ conjunto / condição} = todos os elementos do conjunto que satisfazem a condição.

Regra prática para resolver:

1. Olhe onde o x está (ℝ, ℤ, ℕ...)
2. Aplique a condição nele
3. Liste os elementos que passam no teste
