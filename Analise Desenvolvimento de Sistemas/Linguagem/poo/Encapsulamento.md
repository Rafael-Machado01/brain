# Encapsulamento

É proteger seus atributos e metodos por exemplo atributos não podem ser publicos.

No main não podemos usar por exemplo

```
 id.object = 23;
````

Isso é inaceitavel podemos fazer operações com nossos atributos com métodos

Então temos Public e Private.

Public é para metodos seja funções, setters e getters.

Já o private é reservado para nossos atributos.
