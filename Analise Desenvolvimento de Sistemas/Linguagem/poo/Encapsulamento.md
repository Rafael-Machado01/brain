# Encapsulamento

É proteger seus atributos e métodos; por exemplo, atributos não podem ser públicos.

No main não podemos usar, por exemplo

```
 id.object = 23;
```

Isso é inaceitável; podemos fazer operações com nossos atributos com métodos

Então temos Public e Private.

Public é para métodos, sejam funções, setters e getters.

Já o private é reservado para nossos atributos.
