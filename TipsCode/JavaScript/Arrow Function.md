Criado para reduzir a escrita de funções e para this não variar.

````
let double = function(num) {
return num * 2
}

````
Função normal

````
double = (num) => {
	return 2 *num
	}
````

Caso o return for implícito

````
double = num => 2 * num
````

Ele também é uma função anonima então deve ser atrelada a uma variavel.
