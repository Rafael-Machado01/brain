# Cliente vs Servidor

![[Pasted image 20250729073059.png]]

## Cliente se refere ao navegador do usuário e oque ele é mostrado para ele

## Servidor se refere ao computador ou data center que armazena o código (backend) recebe solicitações do cliente e retorna, algo como um calculo ou reposta.
