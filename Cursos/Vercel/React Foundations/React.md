# React

React é uma biblioteca JavaScript criada pelo Meta (Facebook) para construir interfaces de usuário interativas e baseadas em componentes. Seu principal foco é permitir que desenvolvedores criem UIs de forma declarativa, utilizando um modelo de dados reativo que atualiza a interface automaticamente quando o estado muda. React utiliza JSX, uma extensão de sintaxe que mistura HTML com JavaScript, facilitando a criação de componentes visuais. Com um ecossistema robusto que inclui hooks, roteamento e gerenciamento de estado, React tornou-se a biblioteca front-end mais popular do mundo.
