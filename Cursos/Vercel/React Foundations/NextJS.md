# NextJS

É um framework [[React]], que oferece blocos de construção para criar aplicativos da Web.

![[Pasted image 20250720181854.png]]
Você pode usar o React para criar sua interface do usuário e, em seguida, adotar gradualmente os recursos do Next.js para resolver requisitos comuns de aplicativos, como roteamento, busca de dados e cache - tudo isso melhorando a experiência do desenvolvedor e do usuário final.
