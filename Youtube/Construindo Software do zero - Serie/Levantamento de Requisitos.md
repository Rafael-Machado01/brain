# Levantamento de Requisitos

## Resumo
Antes de codar, precisamos entender o problema

## Conceitos-chave

> [!important] Conceito Principal


Requisito: Necessidade que o software precisa atender
Requisitos funcionais: Tudo que o sistema faz.
- Cadastrar alunos,editar alunos, excluir alunos.
- Registrar pagamentos
- Gerenciar planos
- Emitir relátorio

Requisitos não funcionais: Qualidades do sistemas
- Segurança
- Performace
- Responsividade
- Backups
- Disponibilidade
- Controle de acesso

### Perguntas 
1. Quem vai usar o sistema? 
Professores e recepcionista
2. Qual o maior problema hoje
	Dificuldade de achar registros de alunos
3. Como funciona uma matricula?
	 Pode trancar matricula s/n
4. Como controlam o pagamento?
5. Quando pode excluir informações?

Regras de negocio:
Cada aluno tem que ter um cpf e uma matricula ativa.
Pagamento vencido bloqueia acesso
Apenas admin pode excluir alunos
