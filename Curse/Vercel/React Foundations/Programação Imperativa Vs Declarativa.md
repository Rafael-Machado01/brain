O código que escrevemos em quanto te explicávamos [[DOM Document Object Model]] é um ótimo exemplo de programação **Imperativa** ditando passos de como o [[UI]] deve ser atualizado.

Já a **Declativa** é como se programadores podessem declar o que querem mostrar. No exemplo h1 fique com algum texto.

**A programação imperativa** é como dar a um chef instruções passo a passo sobre como fazer uma pizza. **A programação depreciativa** é como pedir uma pizza sem se preocupar com os passos que é preciso para fazer a pizza.
