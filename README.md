# 🧠 brain

### Segundo cérebro — monorepo pessoal de conhecimento, cursos e projetos

</div>

> Este repositório é meu vault Obsidian pessoal combinado com um portfólio de projetos de software. Aqui converjo anotações acadêmicas, exercícios de cursos online, diário pessoal e projetos práticos que desenvolvo ao longo da minha jornada como estudante de Desenvolvimento de Software.

---

## 📁 Estrutura

```
brain/
├── Curse/           # Exercícios de cursos online (Udemy, TipsCode, Vercel)
├── Diary/           # Diário pessoal (entradas datadas)
├── Fema/            # Anotações da faculdade (Algoritmo, Computação, BD, Estatística, Linguagens, Matemática, Métodos)
├── Linux/           # Guias e anotações sobre Linux
├── Problems/        # Anotações de desafios de programação
├── Projects/        # Projetos de software
│   ├── flux/        # Aplicativo web de organização pessoal (Next.js, Prisma, PostgreSQL)
│   ├── smc-assis/   # Landing page institucional — Secretaria Municipal de Cultura de Assis (Next.js)
│   ├── TG/          # Sistema de gestão — Tiro de Guerra (conceito)
│   ├── oficina/     # Sistema de oficina mecânica em C++ (acadêmico)
│   └── Bank/        # Sistema bancário simples em C++ (acadêmico)
├── Snippts/         # Snippets de código e projetos de teste
├── Storage/         # Imagens e anexos do vault
├── .obsidian/       # Configuração do Obsidian (plugins, temas)
└── .smart-env/      # Configuração do Smart Connections (IA)
```
